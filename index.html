The useful parts of FileZilla, with rsync underneath.

Built for people who move files to servers every day and want transfers to be fast, obvious when they fail, and easy to recover.

⇄

Delta transfers

rsync sends new and modified data instead of blindly transferring everything again.

↻

Resume interrupted work

Large transfers are designed to recover cleanly instead of forcing you back to square one.

✓

No silent failures

Clear exit codes, failed-transfer history and readable logs make transfer errors hard to miss.

⌁

Drag & drop workflow

Move files between local and remote panes, or drag them straight in from Windows Explorer.

⌨

SSH terminal built in

Open an authenticated terminal directly in the current remote directory with a shortcut.

✎

Edit remote files locally

Open a remote file in your editor and automatically upload changes again when you save.

Made for everyday server work.

The interface stays intentionally familiar: local files on the left, remote files on the right, a transfer queue below. Underneath that simple workflow, RsyncZilla uses portable rsync over SSH for atomic, resumable transfers and real error reporting.

Credentials stay off disk Saved sites keep connection metadata, while passwords are passed to SSH in memory.
Open source, MIT licensed No account, no paid tier. Inspect the code, build it yourself, or contribute on GitHub.
